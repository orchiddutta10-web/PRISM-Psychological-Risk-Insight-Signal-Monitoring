fix(security+correctness): post-audit cleanup — 84/84 tests still pass

Code-review findings from a fresh-eyes pass. 5 critical, 6 high, 22 medium, 10
low issues identified; this commit addresses the security- and
correctness-critical ones and a handful of medium-impact quality items.

## Critical fixes

### C1 — Delete 6 unimportable route modules
`services/api/app/routes/{sensors,offline,behavior,guardian,ml,demo}.py`
each failed import (references to missing ORM classes, Pydantic schemas,
or a deleted `demo_simulation_engine.py`). They were silently broken —
main.py never registered them — but they invited future contributors to
wire them up and crash the API on startup. Deleted.

### C2 — Lock down `/api/codebase`
The dashboard route handler exposed the entire repository tree to
anonymous callers. Now gated:
- Returns 404 in production (`NODE_ENV === 'production'`)
- Returns 404 when `NEXT_PUBLIC_ENABLE_CODEBASE_API === 'false'`
- Excludes more directories (.venv, .pio, .firmware-check, .fwcheck,
  .mypy_cache, .pytest_cache, dist, build, uploads, chroma_db, mlruns)
- Wraps fs operations in try/catch so missing subdirs don't 500
- Removes `function scanDir(...): any` for a typed `Array<Record<string, unknown>>`

### C3 — Resolve mobile git conflict markers
`apps/mobile/src/services/api.ts`, `DashboardScreen.tsx`, `OnboardingScreen.tsx`,
and `infra/docker-compose.yml` contained unresolved `<<<<<<<`/`>>>>>>>`
markers. Resulting in 7 API methods calling `this.post('', )` with no
endpoint. Resolved all four files:
- `api.ts` TokenManager: kept the try/catch branch (more robust); added
  proper endpoints + typed responses for all 7 ApiClient methods
  (login, sendOTP, verifyOTP, registerOTP, registerDevice, updateConsent,
  seedBaselines).
- DashboardScreen / OnboardingScreen: kept the clean `socketService`
  pattern over raw WebSocket; removed the duplicated state machines.
- docker-compose.yml: kept the safer `CHANGE_ME` placeholders instead
  of the leaked dev defaults.

### C4 — Merge duplicate `/auth/devices`
`routes/auth.py` had two `@router.get("/devices")` registrations.
FastAPI silently keeps only the first, dropping the admin-broader branch.
Merged: the rich `DeviceWithRiskResponse` shape is kept for guardians,
admins (`ops` / `guardian-admin`) see every device in the system, and
the admin path now writes a `READ_ALL_DEVICES (admin)` audit entry.

### C5 — Tighten default-secret guard
`config.py` already refuses to start in production with default secrets,
but the warning message was terse. Improved: lists every offending key
in the ValueError, plus the exact env vars to set. The defaults remain
in source for dev experience (matching the original PRISM-team design)
but the warning is louder and the production refusal is unambiguous.

## High-priority fixes

### H2 — WebSocket auth before accept()
`telemetry.py` previously called `await websocket.accept()` BEFORE
decoding the JWT, allowing unauthenticated connection attempts to occupy
socket slots. Now:
- Reads the JWT from `Sec-WebSocket-Protocol: bearer.<jwt>` (preferred
  — never reaches proxy access logs)
- Falls back to `?token=` query param with a warning log
- Validates the JWT, then calls `websocket.accept(subprotocol="bearer")`
  on success, `websocket.close(code=1008)` on failure

### H5 — JWT type-mismatch logging
`utils/auth.py get_current_user` / `get_current_device` raised
`credentials_exception` silently on token-type mismatch. Now logs at
warning level with the actual sub + type so incident response can
distinguish "no token" from "wrong token type" (mobile app sending a
device JWT to a guardian route).

## Medium-priority fixes

### M7 — `except Exception: pass` → `logger.warning(...)`
`routes/physio.py` swallowed Redis-cache errors silently. Now logs the
failure with the exception text so operators can spot Redis outages.

### M11 — Delete dead `tryRefreshToken`
`lib/api.ts` had a 14-line function that always returned null and was
never called. Replaced with a typed `readJsonLocalStorage<T>(key, fallback)`
helper that every dashboard page can use to defend against corrupted
localStorage entries (the next step is to update page-level call sites).

### M12 / M14 — localStorage guards
Replaced the page-local `JSON.parse(localStorage.getItem(...))` callsites
with `readJsonLocalStorage`. The helper:
- Returns the fallback on missing key
- Returns the fallback on JSON parse error (with a warning log)
- Removes only the corrupt key (not the entire localStorage) so other
  keys (theme, tour state, conversation id) survive

### M20 — Absolute PRISM_MODEL_DIR
`config.py` defaulted `PRISM_MODEL_DIR` to a relative path that worked
only when uvicorn was launched from `services/api/`. Now defaults to an
absolute path resolved from `Path(__file__).parents[1] / resources / prism`,
so the inference service works regardless of CWD.
