
# PRISM Project Handoff / State File for CMDC AI

## Context
This file was generated by Antigravity (AGY) to synchronize state with CMDC AI. The user is building the PRISM platform, specifically the ESP32 IoT node (PRISM PULSE) which collects physiological data.

## Accomplished Today (State of the Project)
1. **Environment Setup**: `arduino-cli` was installed and permanently added to the Windows PATH. The ESP32 Arduino Core v3.3.11 was installed.
2. **Driver Fix**: Installed the CP2102 USB-to-UART driver so the ESP32 (COM7) could be flashed from the PC.
3. **Firmware Architecture**: Created a non-blocking firmware architecture using `millis()` (instead of `delay()`) to allow parallel execution of sensor reads, serial logging, and LCD updates.
4. **I2C LCD Display**: 
   * Successfully diagnosed and fixed LCD wiring (SCL was mistakenly on GND). 
   * LCD now successfully communicates over I2C at address `0x27` (or `0x3F`).
5. **ISD1820 Audio Module**:
   * Configured on `GPIO 4` to trigger voice prompts based on physiological spikes.
6. **Sensor Pivot (CRITICAL UPDATE)**: 
   * The user **does not have a Grove GSR sensor**. 
   * They are replacing the GSR sensor with a **Pulse Sensor** (Heart Rate).
   * The code needs to be updated to read the pulse rate and display it on the LCD in parallel with the rest of the operations.
