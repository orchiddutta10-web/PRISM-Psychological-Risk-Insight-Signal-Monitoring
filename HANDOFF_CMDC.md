2. **I2C LCD Display**: 
   * LCD wired properly (SDA=21, SCL=22, VCC=5V). 
   * Successfully running dynamically in a non-blocking `millis()` loop alongside sensor acquisition.
3. **ISD1820 Audio Module**:
   * Configured on `GPIO 4` to act as a local voice alert playback mechanism. (Triggered via `HIGH` digital pulse).
4. **Sensor Update 1 - Analog Pulse Sensor**:
   * The user is using a 3-pin analog pulse sensor (S, +, -), **NOT** a GSR sensor, and **NOT** a MAX30102.
   * `S` is connected to `GPIO 34`.
   * VCC is connected to `3.3V` (Critical to protect ESP32 ADC).
   * Heart rate peak detection and BPM calculation logic is fully implemented and tested.
5. **Sensor Update 2 - MPU6050 & Multi-Factor Logic**:
   * We designed a multi-factor psychological anomaly detection system to prevent false positives from exercise.
   * An **MPU6050** has been added to the I2C bus (SDA=21, SCL=22) in parallel with the LCD.
   * **The New Core Logic:** The ISD1820 Voice Alert triggers **ONLY IF**: 
     `[BPM > 110]` AND `[Movement < 1.2g]` continuously for `15 seconds`.
   * The `prism_pulse.ino` firmware was successfully updated (PRISM v4.0) with `Adafruit MPU6050` libraries to handle this sensor fusion logic.
6. **Dashboard Update (prism-node/page.tsx)**:
   * Replaced the GSR "Skin Conductance" card with a **Movement / G-Force** card (amber/orange theme).
   * Heart Rate card now reads from the multi-factor pulse endpoint.
   * Stats strip updated: shows Pulse Readings count + Alerts Fired count.
   * Synthetic demo mode generates realistic BPM (~72) and G-Force (~1.0g) data.
   * About tab updated with real hardware descriptions (Pulse Sensor, MPU6050, ISD1820).
   * Hardware Spec text updated to match actual ESP32 circuit.
   * Live alert badge in header shows current multi-factor alert status.
7. **API Update (physio.py)**:
   * `get_node_status` endpoint now checks **both** `PhysioReading` and `PulseMultiFactorReading` tables.
   * Returns whichever reading is more recent, ensuring the dashboard shows "Connected" when the ESP32 PULSE node is streaming.
